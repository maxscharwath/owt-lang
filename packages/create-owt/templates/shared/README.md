# {{title}}

An [OWT](https://github.com/maxscharwath/owt-lang) app.

```sh
{{pm}} install
{{pm}} run dev        # start the dev server
{{pm}} run typecheck  # type-check .ts and .owt files (markup included)
{{pm}} run build      # type-check and build for production
```

Editor support: install the OWT extension for VS Code, or the OWT plugin for JetBrains IDEs. Neovim, Zed and Helix use the `@owt/language-server`.
